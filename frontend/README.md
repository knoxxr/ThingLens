# ThingLens 웹 화면 (Phase 1–3)

React 19 + TypeScript + Vite, 데이터 조회는 TanStack Query. 차트는 외부 라이브러리 없이 SVG로 직접 그리고,
관계 그래프만 Cytoscape.js를 씁니다 (용량이 커서 관계 구조 화면을 열 때만 불러옴).
외부 CDN·웹폰트를 쓰지 않아 **인터넷이 없는 사내망에서도 그대로 동작**합니다.

## 화면

| 경로 | 화면 | 권한 |
|---|---|---|
| `/scheduler` | 수집 상태: 워커 상태, 현재 속도·시간대, 15분 요청·지연(p95)·부하 오류, 분당 요청 수·지연 차트(1/6/24시간), 작업 대기열, 최근 동기화 주기, 일시정지·재개·지금 동기화 | 관리자·분석가 (제어는 관리자) |
| `/entities` | 엔티티 목록: 유형·프로파일 필터, 검색, 키·관계 수, '관계 없음' 표시 | 로그인 (고객 범위 적용) |
| `/topology` | 관계 구조: 통계, 계층 트리(+계층 밖), 관계 그래프(Cytoscape.js, 에셋 하위만 보기, 관계 없는 엔티티 표시 선택), 선택 엔티티 요약, 구조 이슈 표 | 로그인 (고객 범위 적용) |
| `/entities/:id` | **360°**: 루트까지 경로, 요약 문장, 형제 엔티티(측정 의미·품질·빠진 측정 경고) 또는 하위 요약(에셋), 그래프에서 보기 + 엔티티 상세: 품질 점수, 관계, 텔레메트리 키(의미·종류·판정·보고 주기·품질·문제), 속성(역할), 변경 이력 | 로그인 (고객 범위 적용) |
| `/changes` | 변경 이력 전체 (종류별 필터) | 로그인 (고객 범위 적용) |
| `/catalog` | 데이터 카탈로그: (프로파일, 키)별 데이터 종류·의미·단위·신뢰도·근거, **검토 대기 → 의미 확정**, 의미별 묶음, 속성 역할, 확정 기록 | 로그인 (확정은 관리자·분석가) |
| `/quality` | 데이터 품질: 평균 점수·분포, 심각도별 건수, 항목별 미해결, 점수 낮은 엔티티, 문제 목록 | 로그인 (고객 범위 적용) |
| `/admin` | 사용자 목록·추가(고객 담당자는 고객 선택), 감사 로그 | 관리자 |

라이트/다크 모드는 OS 설정을 따릅니다. 상태 표시는 색과 함께 글자·아이콘을 같이 써서 색만으로 의미를 전달하지 않습니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173 , /api 는 127.0.0.1:8000(thinglens api)으로 프록시
npm run build      # dist/ 생성 (타입 검사 포함)
```

## 배포

빌드 결과(`dist/`)를 백엔드가 같이 제공합니다 — 별도 웹 서버 불필요.

```bash
THINGLENS_WEB_DIR=/path/to/frontend/dist thinglens api --host 0.0.0.0 --port 8000
# 브라우저: http://<서버>:8000/
```
